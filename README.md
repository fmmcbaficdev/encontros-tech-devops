# Encontros Tech DevOps

Projeto do bootcamp DevOps Pro — pipeline completo de CI/CD com Docker e Kubernetes.

## Estrutura

```
encontros-tech-devops/
├── app/          # Código da aplicação
│   └── tests/   # Testes automatizados
├── docker/      # Dockerfiles e configurações
├── k8s/         # Manifests Kubernetes
├── scripts/     # Scripts utilitários
└── .github/
    └── workflows/ # Pipelines CI/CD (GitHub Actions)
```
